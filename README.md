# スーパースローボクシング v0.8

2026-09-08 / Codex。ローカルCPU試作。ユーザーの「とりあえずボクシングルールでつくってみる」に基づき、蹴りを除外して着手。時間方式の最終採用は未確定で、常時スローを試作の既定にした。

## 公開版
GitHub Pagesで遊べる静的プロトタイプ: https://aratama-ship-it.github.io/super-slow-kickboxing/

## 起動
ワークスペース直下から:

```sh
python3 -m http.server 8876 --bind 127.0.0.1 --directory "apps/game-app/super-slow-kickboxing"
```

ブラウザで http://127.0.0.1:8876/boxing/ を開く。ゲーム入口はindex.html。ES Modulesのためfile:で直接開かずHTTPで表示する。ゲーム本体は外部通信やアカウント設定を使わない。

## 実装した範囲
- 一人称3D、体積のあるマネキン、自分の赤い左右グローブ、青いグローブの相手、有限のリング。
- オーソドックス固定。身体と両足の向きを正面から45°傾け、左手・左肩・左足を前、右手・右肩・右足を後ろへ置く。ガード移動中と攻撃の溜めでも前後関係を保つ。構えデータは後の左右切替で差し替えられる境界にした。
- 左ジャブ、右ストレート、左右フック、左右アッパー。頭／胴を選択。
- パンチの拳同士が0.20m以内で接触した場合、衝突力の弱い側の腕だけを4 TU弾く。弾かれた腕は攻撃・防御に使えず、強い側のパンチは続行する。同じ力なら双方を3 TU弾く仮ルール。
- 左右それぞれのパーリング／顔のブロッキング／お腹ブロッキング。顔とお腹のブロッキングは3 TUで切り替えて維持。攻撃・パーリング・弾かれ動作中の手は元のガードを使えない。
- パーリングは1回入力で準備2.4 TU → 有効な払い1.6 TU → 戻り2.4 TU。自分基準で左手は左外、右手は右外へ払い、有効区間で拳中心間0.22m以内に触れた頭へのジャブ／ストレートだけを外す。成功は1動作1件で、攻撃腕だけを4 TU弾く。準備・戻りの隙は連打や同じ手の攻撃／防御切替で消せず、反対の手は独立して操作できる。空振りもスタミナ5を使い、終了後は元の顔／お腹ブロッキングへ戻る。顔のブロッキングは頭への全パンチを1ダメージで受け、お腹ブロッキングは胴へのパンチを無傷で受け、双方の腕を弾かない。必要な左右の手が合っている場合だけ成立する仮ルール。
- 始動中のフェイント、制動と戻り、次の技1件の予約と差替え・取消・期限。
- 前後の足運び、左右への頭位置の退避、射程、簡易的な拳と部位の接触。
- スタミナ、体力、同時ヒット、KO・時間切れ・引き分け。正式なボクシング採点ではない。
- 読み合いCPU、ジャブ練習、静止相手。CPUは1.2 TU遅延した公開観測から、技種・狙いがまだ不明な腕の初動を見て一定確率でパーリングを予測選択し、外れる可能性を持つ。開始／停止／再戦。非表示・blurで練習を停止。
- パンチ、左右別の守り、足運び、頭移動、フェイント、一時停止の18操作を画面から変更できるキー設定。同じキーは既存操作と自動で入れ替え、ブラウザ内へ保存。初期設定へ戻せる。

## 制限と未実装
- 蹴り、オンライン、サウスポーへの構え切替、クリンチ、ダウンとカウント、正式採点は未実装。
- パーリングは各手で固定の外払い。上下／内外を自由に指定する操作、左右別の自由な手位置、キャッチ、スウェー、ダッキングは未実装。
- 攻撃は1件ずつ。左右のパンチを重ねる連係や、パンチ中の足運びは許可していない。
- 動作時間・射程・威力・CPU方針はゲーム用仮値。格闘経験者による自然さ・面白さの確認は未実施。
- パンチ同士は拳の中心距離、身体への攻撃は拳位置と頭／胴の楕円体、ガードのモードで判定。腕全体の衝突、速度・質量・角度を含む自由物理ではない。
- 人体は自作のプリミティブによる体積モデル。腕は肩／肘／拳を結ぶ簡易リグで、実人体の関節角・骨長を拘束していない。本人校正前のフォーム。
- 対応検証の中心はPC。モバイルでも操作できるレイアウトだが実スマホの操作感・性能は未確認。
- キー設定は現在のブラウザと端末ごとに保存する。別ブラウザ・別端末への同期や設定ファイルの書き出しは未実装。

## コードの境界
- core.mjs: ブラウザ非依存の戦闘規則、技データ、左右別の防御・弾かれ状態、共有する拳位置、公開観測、CPU。
- view.mjs: Three.js描画。拳位置はcore.mjsのgloveLocalから取得。
- app.mjs: 入力、固定刻みの更新、停止、UI。世界時間とUI反応を分離。
- keymap.mjs: 18操作の既定キー、保存値の検証、表示名、重複時の入れ替え。
- core.test.mjs: node標準の意味的なルール検証。
- keymap.test.mjs: キー設定の完全性、壊れた保存値からの復帰、重複キーの入れ替えを検証。
- vendor/: このワークスペースの既存three 0.185.1から2モジュールを複製。MITライセンスを同梱。出典 https://github.com/mrdoob/three.js/tree/r185 と公式 https://threejs.org/docs/ を参照。モデル・テクスチャの第三者素材は未使用。
