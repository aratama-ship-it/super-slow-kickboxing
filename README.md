## 実装した範囲
- 一人称3D、体積のあるマネキン、自分の赤い左右グローブ、青いグローブの相手、有限のリング。
- オーソドックス固定。身体と両足の向きを正面から45°傾け、左手・左肩・左足を前、右手・右肩・右足を後ろへ置く。ガード移動中と攻撃の溜めでも前後関係を保つ。構えデータは後の左右切替で差し替えられる境界にした。
- 左ジャブ、右ストレート、左右フック、左右アッパー。頭／胴を選択。頭狙いの左ジャブは拳中心の終点を従来より10cm下げ、額ではなく鼻から口付近へ向ける。左右の公平性を保つため自分と相手へ同じ値を使い、他のパンチと胴狙いの高さは変えない。構え中は左右の拳を各軸約1〜2cmの範囲で異なる周期・位相により動かし続ける。左ジャブ固有の引きや溜めは置かず、2.7 TUの固定tickから拳、左前足、腰、胸、頭、肩線を同時に始動する。前足は最大約10cm、腰は約3.5cm、胸は約5cm、頭は約4.5cm前進し、体幹を約4°回してから一緒に戻す。パーリングで攻撃腕が弾かれた場合も接触時の姿勢から構えへ戻る。後ろ足を構え位置へ残し、フォーム用の動きは選手本体の位置・射程・命中判定・CPUの観測条件を変えない。

## 制限と未実装
- 蹴り、オンライン、サウスポーへの構え切替、クリンチ、ダウンとカウント、正式採点は未実装。
- パーリングは各手で固定された小さい下方向の動作。上下／内外を自由に指定する操作、左右別の自由な手位置、キャッチ、スウェー、ダッキングは未実装。
- 攻撃は1件ずつ。左右のパンチを重ねる連係や、パンチ中に別入力で足運びを重ねる操作は許可していない。左ジャブ固有の前足同期は自動で行う。
- 動作時間・射程・威力・CPU方針はゲーム用仮値。格闘経験者による自然さ・面白さの確認は未実施。
- パンチ同士は拳の中心距離、身体への攻撃は拳位置と頭／胴の楕円体、ガードのモードで判定。腕全体の衝突、速度・質量・角度を含む自由物理ではない。
- 人体は自作のプリミティブによる体積モデル。腕は肩／肘／拳を結ぶ簡易リグで、実人体の関節角・骨長を拘束していない。本人校正前のフォーム。
- 対応検証の中心はPC。モバイルでも操作できるレイアウトだが実スマホの操作感・性能は未確認。
- キー設定は現在のブラウザと端末ごとに保存する。別ブラウザ・別端末への同期や設定ファイルの書き出しは未実装。
- 組み合わせ検証の機械判定は現在の仮ルールとの一致を示す。動作の自然さや競技としての妥当性は証明せず、本人の採否はブラウザ内だけに保存する。
