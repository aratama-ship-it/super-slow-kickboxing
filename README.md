# スーパースローボクシング v0.2

2026-09-07 / Codex。ローカルCPU試作。ユーザーの「とりあえずボクシングルールでつくってみる」に基づき、蹴りを除外して着手。時間方式の最終採用は未確定で、常時スローを試作の既定にした。

## 公開版
GitHub Pagesで遊べる静的プロトタイプ。公開URLはリポジトリ作成後にここへ記載する。

## 起動
ワークスペース直下から:

```sh
python3 -m http.server 8876 --bind 127.0.0.1 --directory "apps/game-app/super-slow-kickboxing"
```

ブラウザで http://127.0.0.1:8876/boxing/ を開く。ゲーム入口はindex.html。ES Modulesのためfile:で直接開かずHTTPで表示する。ゲーム本体は外部通信やアカウント設定を使わない。

## 実装した範囲
- 一人称3D、体積のあるマネキン、左右の自分のグローブ、有限のリング。
- オーソドックス固定。左手・左肩・左足を前、右手・右肩・右足を後ろへ置き、ガード移動中と攻撃の溜めでも前後関係を保つ。構えデータは後の左右切替で差し替えられる境界にした。
- 左ジャブ、右ストレート、左右フック、左右アッパー。頭／胴を選択。
- 前方／側面／胴／緩めた構え。3 TUのガード移動と、攻撃中の片手の防御欠如。
- 始動中のフェイント、制動と戻り、次の技1件の予約と差替え・取消・期限。
- 前後の足運び、左右への頭位置の退避、射程、簡易的な拳と部位の接触。
- スタミナ、体力、同時ヒット、KO・時間切れ・引き分け。正式なボクシング採点ではない。
- 読み合いCPU、ジャブ練習、静止相手。開始／停止／再戦。非表示・blurで練習を停止。

## 制限と未実装
- 蹴り、オンライン、サウスポーへの構え切替、クリンチ、ダウンとカウント、正式採点は未実装。
- パリーと独立した左右ガードは元設計の検討項目として残す。初期試作は共有プリセット＋攻撃手の無防備。
- 攻撃は1件ずつ。左右のパンチを重ねる連係や、パンチ中の足運びは許可していない。
- 動作時間・射程・威力・CPU方針はゲーム用仮値。格闘経験者による自然さ・面白さの確認は未実施。
- 拳位置と頭／胴の楕円体との接触、ガードのモードで判定。自由物理・腕と拳の詳細衝突ではない。
- 人体は自作のプリミティブによる体積モデル。腕は肩／肘／拳を結ぶ簡易リグで、実人体の関節角・骨長を拘束していない。本人校正前のフォーム。
- 対応検証の中心はPC。モバイルでも操作できるレイアウトだが実スマホの操作感・性能は未確認。

## コードの境界
- core.mjs: ブラウザ非依存の戦闘規則、技データ、共有する拳位置、公開観測、CPU。
- view.mjs: Three.js描画。拳位置はcore.mjsのgloveLocalから取得。
- app.mjs: 入力、固定刻みの更新、停止、UI。世界時間とUI反応を分離。
- core.test.mjs: node標準の意味的なルール検証。
- vendor/: このワークスペースの既存three 0.185.1から2モジュールを複製。MITライセンスを同梱。出典 https://github.com/mrdoob/three.js/tree/r185 と公式 https://threejs.org/docs/ を参照。モデル・テクスチャの第三者素材は未使用。

## 検証
`node --test "apps/game-app/super-slow-kickboxing/boxing/core.test.mjs"` をワークスペース直下から実行。
14テスト全通過。全ガードで左手が前・右手が後ろになるオーソドックスの構え、先置き／後出しガード、フックとガード、胴の打ち分け、攻撃手の無防備、早い／遅いキャンセル、距離と頭位置、1件予約、移動排他、相打ちKO、公開観測、停止、固定seedのCPU完走を検証。
v0.2追加確認では、1188px幅の一人称画面で左右の拳と相手の左肩・左足の前後差を目視した。390px幅のブラウザ（内容幅375px）では構えラベルを表示したまま横溢れ0px。コンソールエラー0件。Three.jsがPCFSoftShadowMapをPCFShadowMapへ読み替える非推奨警告は残る。
ブラウザでは18項目を確認。開始、守りの移動、予約、フェイント、キー回避、足運び、停止／再開、blur停止、リセット、命中表示、終了、再戦、ヘルプ停止、速度と時計、練習モード、390px操作、通常URLにテストAPIがないこと、通常URLでのCPU戦進行。詳細な検証記録と画像は公開リポジトリへ含めず、ローカルワークスペースに保持。
PC1440px／モバイル390pxで全体横溢れなし。初期画面のdesign-lintはNG 0、WARN 0。開始前の無効ボタンはコントラスト点検の対象外であり、全プレイ局面の自動監査ではない。3DはChromiumのWebGL（SwiftShader）で描画・スクリーンショット確認済み。実機GPU性能と実スマホは未検証。
開始後の有効ボタン20個を測定し、全て44px以上、文字コントラスト最小11.30:1。ホバー文字色と背景も確認し、白黒でも選択とラベルが判別できることを目視した。
v0.1作成時は元の設計書index.htmlとPROJECT_NOTES.mdも更新。v0.2ではboxing/のcore.mjs、view.mjs、index.html、boxing.css、core.test.mjs、README.mdとdesign/BOXING_TOKEN_SHEET.mdを更新した。Three.jsの複製は変更なし。削除・移動・公開なし。
`?test` で開いた場合だけwindow.__boxingTestにローカル検証用の時間送りとスナップショットを公開する。通常URLにはない。ネット対戦は存在しない。
